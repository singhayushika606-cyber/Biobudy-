# BioBuddy - Your Biology Learning Friend

## Problem Statement
Students find Biology hard words, long theory and diagrams difficult to understand. Teacher is not available all the time.

## Our Solution
BioBuddy makes Biology easy and fun. It explains topics in simple words, gives easy notes, diagrams and quiz. Students can learn anytime, anywhere.

## How It Works
1. Student selects a Biology topic
2. BioBuddy explains in simple language
3. Shows easy notes + diagram
4. Gives small quiz to test learning

## Features
- Simple explanation
- Easy notes
- Diagrams
- Quiz

## Testing
Tested 5 times with different topics like Photosynthesis, Human Heart, Cell. Working successfully.
